# Colección propia de plantillas

Revisión del 3 de octubre de 2026. Las 142 alternativas de Más plantillas utilizan este compositor propio. Diez composiciones anteriores ya revisadas se mantienen: Profesional, Limpio, Industrial, Caligráfico, Sólido, Colorido, Atlántico, Órbita, Optimista y Áurea.

Las otras 132 tarjetas se sustituyeron individualmente por doce familias con once paletas cada una: Editorial, Archivo, Compás, Prisma, Atelier, Cronología, Umbral, Horizonte, Módulo, Esencia, Cuaderno e Índice. Las variantes cambian sus colores; las familias cambian distribución, jerarquía, proporciones, fechas y secciones. La [tabla de sustituciones](../../docs/legal/revision-plantillas.md) registra el ID anterior y la composición actual. No se afirma que sean 132 estructuras diferentes ni que el trabajo garantice ausencia de reclamaciones.

catalog.mjs combina las diez composiciones previas y collection.mjs. preview.mjs pagina los documentos y designs.css contiene sus estilos. Se reutilizan el modelo de datos y utilidades de texto y enlaces; se retiraron las medidas, árboles de estilo, formas y fondos de las referencias. Los identificadores antiguos son claves de compatibilidad. Inter y EB Garamond tienen SIL Open Font License, incluida con los archivos. No hay imágenes decorativas descargadas de los catálogos externos.

Abrir drafts/originals/index.html desde un servidor HTTP local. Permite buscar, cambiar entre muestra normal y larga, y activar una foto ficticia generada con ImageGen. El banco de trabajo no usa Authentication ni Firestore. Las URLs anteriores de los dos catálogos redirigen a este banco local.

Las 142 tarjetas siguen bloqueadas en la aplicación. Clásica, Compacta, el compositor público, los CVs guardados y todos los archivos PDF existentes se conservaron. Las miniaturas son las primeras páginas del compositor actual: diez archivos original-*.webp y 132 archivos owned-*.webp.

Se verificaron 474 escenarios en navegador: cada diseño con muestra normal, larga y fotografía, y doce familias representativas con saltos manuales, párrafos extensos enlazados, competencias largas y documento vacío. Se comprobaron contenido perdido o duplicado, enlaces, límites del papel y solapamiento con el pie o foto. La regeneración de miniaturas no crea ni modifica PDF.
